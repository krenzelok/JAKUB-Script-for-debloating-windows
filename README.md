# How to run it
 First you need to download it
 Run it as administrator

# What does it do
 1. Uninstall Edge
 2. Remove Telemetry
 3. Set services to Manual
 4. Remove AI,Brave Telemetry and a bunch of stuff
 5. Remove Microsoft store (Optional) or only bloat
 6. Install essential programs like 7zip (Optional firefox if you dont have a browser)
